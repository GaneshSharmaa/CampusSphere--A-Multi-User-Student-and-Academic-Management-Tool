Features are being implemented incrementally with a focus on writing clean, maintainable, and production-oriented code rather than rapidly adding functionality).

**This is a SaaS product aimed at building a complete Student Management System that can be used by educational institutions such as schools, colleges, universities, and tutors.**

### Features

Here, the features mentioned are both already added or planned for the future.

- JWT Authentication
- Role-Based Access Control (RBAC)
- Teacher Dashboard
- Student Dashboard
- User Profile Management
- Academic Management (Departments, Courses, Subjects, Enrollment)
